# pi-ui-status

Private local-v1 package for the Pi UI Status Surface.

The package currently establishes the independently loadable extension entry and package-local test seam. Capabilities are added one at a time by their own feature PRs, beginning with Working.

During repository development, load the root `pi-harness-kit` aggregate through `.pi/settings.json`. Do not also load this package directly in the same pi session.
