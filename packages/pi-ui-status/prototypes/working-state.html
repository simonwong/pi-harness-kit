一次性逻辑原型 · Issue #29

Pi 什么时候才算真的完成工作？

这个原型用来验证：一次底层运行结束、自动重试、排队继续、最终结束、取消、错误和 reload 之间，Working 状态怎样才能始终真实且安静。你可以亲自驱动生命周期、比较三种 呈现方案，并在每次操作后查看完整状态。

公共 API 限制：每次底层 agent_end 发生时， Pi host 都会清除 Working row；只有 agent_settled 才能证明不会再自动继续。这个原型会把这段空隙明确展示出来，而不是藏起来。
